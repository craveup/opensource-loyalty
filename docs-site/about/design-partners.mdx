The program is for ordering platforms, restaurant technology teams, and
multi-location operators that control a server-side checkout integration and
can provide sanitized events and a test tenant.

A typical pilot maps source semantics, certifies an adapter, runs evaluate
through partial refund in staging, rehearses member/balance migration,
documents security and rollback, and then chooses Cloud, self-hosting, or a
clean stop. Success is a reproducible lifecycle report—not a logo.

LIP will not publish a partner name, metric, screenshot, or quote without
written approval.
